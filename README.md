# Touchline — Pocket Football

An original mobile-browser 2D arcade soccer prototype with five-a-side AI, passing, shooting, goals, match timer, and touch controls. Not a full 3D simulator or a native mobile app.

Run from this directory: `python3 -m http.server 8000 --bind 0.0.0.0`.
No installation or external assets required. Use WASD/arrows to move, J to pass, K to shoot, L to switch players, or the touch controls. Attack the right goal.

The server runs inside the cloud environment; this onboarding interface does not expose its port to your browser. Use a local copy or a supported web hosting service to play on your own device.
